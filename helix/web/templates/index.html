The artefact

A gold row you can read. A zip you can run.

Export schema is {"input", "output", "id"}. Gold and synthetics are stored apart. If you train, C7X-IO returns a QLoRA adapter — not a merged 7B–30B dump — plus load_adapter.py. Catalog bases are Apache-2.0 or MIT instruct. Default is Qwen2.5 7B Instruct.
