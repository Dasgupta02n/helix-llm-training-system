Security · Early beta

Security overview

Honest status: Helix is an early product. We apply practical safeguards appropriate to a multi-tenant SaaS beta. We do not currently claim SOC 2 / ISO certifications on this page.

What we do today

  • Transport — HTTPS at the public edge when TLS is configured for c7xai.in.
  • Auth — password hashing, session/JWT-style access tokens, optional email verification and admin approval gates.
  • Isolation — workspace/tenant scoping on library, jobs, and mining state.
  • Abuse controls — request size limits and rate limiting on sensitive routes.
  • Secrets — production requires a strong app secret; provider API keys via environment configuration, not client-side code.
  • Gather vs invent — scrapes come from configured gather tools or your corpus; the LLM is instructed not to invent source content.

What you should assume

  • Beta software may contain bugs; do not store highly regulated personal data until we publish a formal compliance program.
  • Content sent to LLM/gather providers is processed under those providers’ security models.
  • You control what you paste into corpus and plans—treat that as production data for your risk profile.

Roadmap (tell us what you need)

SSO/SAML, private networking, and formal audits are on the conversation list for enterprise customers—not yet product claims.
